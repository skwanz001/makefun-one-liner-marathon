# One-Liner Marathon

One original one-line comedy joke, entered in make.fun's
[One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2)
bounty. `main.py` (Python 3.13, standard library only) writes the joke to
`/output/entry.txt` — a single line of 156 characters.

> The self-checkout flagged my reusable bag as an 'unexpected item,' so now I steal one grape per visit, just to give the machine something to be right about.

The joke is fixed text, written for this bounty: the machine accuses you of
stealing, so you commit a tiny crime just to validate it. No setup without a
punchline, no shock for shock's sake.
